### 🖥️ UIUX
1. 구형 해상도에 맞춘 좁은 화면 폭을 와이드 레이아웃으로 개선하고 여백을 살려 답답함 해소
2. 작은 폰트와 좁은 간격으로 저하된 가독성을 폰트 크기·명도 대비 최적화로 개선
3. 메인 Visual : 다크 톤 배경과 정밀 기계 클로즈업 비주얼 배너, 슬라이더 내비게이션으로 첨단 기술력 강조
4. 회사소개 : 4가지 핵심 가치(최고의 기술력, 지속 가능한 미래, 고객 중심 혁신, 글로벌 네트워크)를 아이콘과 함께 카드형 UI로 정돈
5. 제품소개 : 다크 네이비 배경 위 카드 인터페이스와 탭 메뉴로 주요 제품군을 손쉽게 탐색하도록 설계
6. ESG경영 : 환경·사회·지배구조 세 가지 축을 오버레이 카드로 표현해 핵심 실천 과제 전달
7. 인재채용 : 채용 FAQ를 아코디언 UI(토글)로 구성해 필요한 정보만 펼쳐볼 수 있도록 구현
8. NEWS : 보도자료 및 사회공헌 소식을 썸네일과 날짜별 리스트로 정돈해 최신 소식을 신속하게 파악
9. 복잡한 메뉴 동선을 정리하고 hover/click 인터랙션이 있는 GNB로 정보 탐색 시간 단축
